## 🚀 Overview
An interactive, high-performance personal portfolio and resume website crafted using **pure semantic HTML5, modern vanilla CSS3, and lightweight vanilla JavaScript** (zero external frameworks or heavy libraries).

Designed with a sleek dark aesthetic and warm terracotta/orange accents inspired by [buildwithclaude.in](https://buildwithclaude.in/).

---

## 🛠️ Tech Stack & Architecture
- **HTML5:** Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<canvas>`)
- **CSS3:** Custom Properties (`:root`), Flexbox, CSS Grid, Fluid Typography (`clamp()`), Keyframe animations, Glassmorphism backdrop-filters, and media queries.
- **JavaScript (Vanilla):** 
  - Dynamic Typewriter Effect
  - Interactive Particle Physics Canvas with mouse repulsion & proximity lines
  - Smooth Scrolling & Intersection Observer for active section highlighting
  - 3D Card Tilt on mouse move
  - Animated Numeric Counters for achievements
  - Custom Cursor Glow Trail
  - Scroll Progress Indicator
  - Mobile Hamburger Menu drawer
